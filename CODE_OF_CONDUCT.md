# Code of Conduct

DBB-HACK is a small, free, open-source project. The bar is simple:

- Be respectful in issues, PRs, and discussions. No harassment, insults, or personal attacks.
- Stay on topic: bug reports, feature requests, and security findings are welcome; spam and self-promotion are not.
- This is an **offensive security tool**. Only discuss, request, or share usage against systems you own or are explicitly authorized to test. Requests for help attacking third-party systems will be closed without discussion.
- Report a vulnerability in DBB-HACK itself privately (see `SECURITY.md`), not as a public issue.

Violations may get a comment removed, a PR closed, or (for repeated/serious cases) the person blocked from the repo. Contact **hola@dontbuybuild.cl** if you need to report conduct that broke these rules.

*Español: mismo criterio — respeto, en el tema, y nunca pedir ayuda para atacar sistemas de terceros. Reporta vulnerabilidades por `SECURITY.md`, nunca como Issue público.*
